# Concrete Pour Planner

A Tkinter desktop app for planning concrete slab pours. It supports drawn or typed slab outlines, concrete volume and cost estimates, truck rotations and arrivals, set-time checks, project save/open, and Excel-compatible CSV export.

## Install

Python 3.10 or newer is recommended. Tkinter is included with most Python installations.

```bash
pip install -r requirements.txt
```

Required packages:

- `tkintermapview` - Esri satellite map
- `numpy` - numeric support
- `matplotlib` - plotting support

## Run

```bash
python app.py
```
